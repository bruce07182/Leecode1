1. Why do we need a database?

A file stores data. JSON gives it structure. A database helps multiple users search, update, relate and protect that data reliably.

Example: JSON is convenient for one person's settings. When a store needs to find every order for a customer, track inventory, and handle simultaneous updates, a database is more useful. Databases can also store JSON; they are not mutually exclusive.

Deep dive · relational databases

Tables contain rows (records) and columns (fields). A primary key identifies a row. A foreign key connects rows in different tables. Indexes speed up selected lookups; transactions help keep multi-step changes consistent.

SQL is the language used to query and modify many relational databases, including SQLite and PostgreSQL (used by Supabase).

2. Setup and runtime

No installation required. This practice uses SQLite in your browser through sql.js (WebAssembly). The sample database is recreated when you reload. Queries run locally, not against your Supabase account.

In a real app: Browser → API / Supabase → PostgreSQL. Never give learners direct SQL access to your production database.
